## Выбранная граница

Использование агента внутри бизнеса, в том числе для разработки коммерческих продуктов, разрешено. Предоставление другим конкурирующего продукта или сервиса на основе проекта требует отдельного разрешения правообладателя. По тексту Perimeter ограничение может распространяться и на бесплатные конкурирующие предложения.

Ниже — поясняющие примеры применения выбранной политики. Они не добавляют исключений и не заменяют условия LICENSE.

| Сценарий | Как его рассматривает политика |
|---|---|
| Компания использует агента внутри команды для поиска по своей конфигурации | Разрешённое внутреннее использование, включая коммерческую разработку |
| Программист использует агента как инструмент при разработке коммерческого продукта, не предоставляя клиентам конкурирующего агента или сервиса | Сам коммерческий характер разработки не запрещён |
| Агент дорабатывается для внутренней работы | Разрешено для допустимых целей по LICENSE |
| Агент переименовывается и предлагается клиентам как собственный конкурирующий продукт | Требуется отдельное разрешение |
| На основе агента предоставляется конкурирующий API, SaaS, плагин или библиотека | Требуется отдельное разрешение; вид интерфейса не снимает ограничение |
| Конкурирующий продукт на основе агента предоставляется бесплатно | Бесплатность сама по себе не делает такое использование допустимым |
